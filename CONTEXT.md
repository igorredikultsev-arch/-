## Что это и где сейчас

- **Автослот** — сайты с онлайн-записью для шиномонтажей и автосервисов (Пермь, потом вся РФ). Продаём через персональное демо: делаем в админке сайт с названием и услугами конкретного сервиса и отправляем владельцу ссылку. Цена: 3 500 ₽ подключение (в него входит первый месяц), 990 ₽/мес со второго месяца, гарантия возврата 14 дней (пробного периода нет с 4 октября).
- **Владелец проекта** — Игорь, 18 лет, самозанятый, звонить не любит, продаёт сообщениями (Telegram/VK/WhatsApp).
- **В продакшене:** https://avtoslot.ru — с 4 октября VPS Timeweb Cloud в Москве (копия новосибирского, который сутки был без сети), код в `/opt/avtoslot`, Docker Compose (db, app, caddy). Через ~3 недели Игорь планирует переезд к другому хостингу и запасной сервер.
- **Ветка:** `claude/admiring-davinci-ej5p3n` (ветки main нет). Сервер собирается из неё.
- **Обновление сервера:** доступа к серверу у ассистента нет. С октября 2026 сервер обновляется сам: `deploy/autoupdate.sh` (cron, раз в 5 минут) забирает новый коммит из ветки сервера после зелёной проверки GitHub Actions и запускает `update.sh`, обычно через 10–25 минут после пуша. Автообновление включено 3 октября (`deploy/autoupdate.sh install`). Журнал: `/opt/avtoslot/app/deploy/update.log`. Вручную: `update.sh`. Образы собирает GitHub Actions (`.github/workflows/ci.yml`: типы, тесты с базой, сборка образов, миграции и запуск сайта из образа) и публикует в `ghcr.io/igorredikultsev-arch/avtoslot` (теги `app-<коммит>`, `migrate-<коммит>`); сервер только скачивает их, версия — `AVTOSLOT_TAG` в `.env`. Пуш в ветку сервера = выкладка: пушить только проверенное.
- **Посты клиенту не показываем** (решение Игоря): число постов — внутренняя ёмкость для расчёта окон, на сайте «План» и «Такси» показывают только время, когда сервис занят целиком. В демо число постов взято наугад, поэтому факт «N поста» в демо не выводится.
- **Демо пачкой:** админка → «Из таблицы», загрузить .xlsx/.csv с колонками «Название», «Адрес», «Телефон» (+ по желанию остальные поля формы и «Первое сообщение» с `[ссылка на демо]`). Повторная загрузка не задваивает.

## Что сделано (версия 1 плана + запуск)

- Сайт автосервиса `/s/<slug>` в трёх темах (с 3 октября, старые «Гараж», «Книжка», «Асфальт» убраны миграцией):
  - **«Боковина»** (`tire`): тёмная, SVG-шина в шапке, выбор радиуса R13-R22 сразу показывает цену (радиусы берутся из названий услуг, `lib/radius.ts`);
  - **«План»** (`plan`): светлая, стоянка, где каждое место — время записи выбранного дня; где сервис занят целиком — машина, свободное время кликабельно;
  - **«Такси»** (`taxi`): чёрно-белая, одна шкала загрузки на день (клик выбирает время в месте нажатия) и ближайшее свободное время, шторка записи.
  `GET /api/s/<slug>/load?date=` отдаёт только промежутки, когда заняты все посты (`fullBusy` в `lib/slots.ts`), без данных клиентов. Акцентный цвет задаётся в админке.
- **Выбор стиля в демо:** сверху панель «Боковина / План / Такси» (ссылка `?theme=…`, тему ставит layout через заголовок от `proxy.ts`) и кнопка «Выбрать этот стиль» (`POST /api/s/<slug>/theme`, только для демо). Выбор и дата видны в админке (колонка «Стиль»).
- Есть мобильная и (с последнего коммита) компьютерная версия: на ≥960px шапка на всю ширину с карточкой «адрес / сегодня / телефон», ниже две колонки — контент слева, форма записи справа (sticky).
- Кабинет владельца `/cabinet`, админка `/admin` (воронка, быстрое демо, подключение, оплаты), главная avtoslot.ru, `/offer`, `/privacy`.
- Импорт демо из таблицы (админка → «Из таблицы», `lib/sheet.ts` читает xlsx/csv без библиотек, `lib/demo-import.ts`), первое сообщение хранится в `Lead.firstMessage`.
- 44 теста (vitest), production-сборка проходит.
