Короткая выжимка, чтобы продолжить работу без истории переписки. Полный план продукта — [PLAN.md](PLAN.md), запуск и деплой — [README.md](README.md).

## Что это и где сейчас

- **Автослот** — сайты с онлайн-записью для шиномонтажей и автосервисов (Пермь, потом вся РФ). Продаём через персональное демо: делаем в админке сайт с названием и услугами конкретного сервиса и отправляем владельцу ссылку. Цена: 3 500 ₽ подключение, 790 ₽/мес, 14 дней бесплатно.
- **Владелец проекта** — Игорь, 18 лет, самозанятый, звонить не любит, продаёт сообщениями (Telegram/VK/WhatsApp).
- **В продакшене:** https://avtoslot.ru — VPS Timeweb Cloud (Новосибирск, Ubuntu 26.04, 1 ядро, 1 ГБ, 15 ГБ), код в `/opt/avtoslot`, Docker Compose (db, app, caddy).
- **Ветка:** `claude/admiring-davinci-ej5p3n` (ветки main нет). Сервер собирается из неё.
- **Обновление сервера:** доступа к серверу у ассистента нет. С октября 2026 сервер обновляется сам: `deploy/autoupdate.sh` (cron, раз в 5 минут) забирает новый коммит из ветки сервера после зелёной проверки GitHub Actions и запускает `update.sh`, обычно через 10–25 минут после пуша. Включается один раз командой `/opt/avtoslot/app/deploy/autoupdate.sh install`; пока Игорь её не запустил, обновляет вручную `update.sh`. Поэтому пуш в ветку сервера = выкладка: пушить пачками и только проверенное (сборка на 1 ядре 10–15 минут, место на диске ограничено).
- **Демо пачкой:** админка → «Из таблицы», загрузить .xlsx/.csv с колонками «Название», «Адрес», «Телефон» (+ по желанию остальные поля формы и «Первое сообщение» с `[ссылка на демо]`). Повторная загрузка не задваивает.

## Что сделано (версия 1 плана + запуск)

- Сайт автосервиса `/s/<slug>` в трёх темах (с 3 октября, старые «Гараж», «Книжка», «Асфальт» убраны миграцией):
  - **«Боковина»** (`tire`): тёмная, SVG-шина в шапке, выбор радиуса R13-R22 сразу показывает цену (радиусы берутся из названий услуг, `lib/radius.ts`);
  - **«План»** (`plan`): светлая, вид сверху на посты выбранного дня, свободные места кликабельны;
  - **«Такси»** (`taxi`): чёрно-белая, шкала загрузки постов на день и ближайшее свободное время, шторка записи.
  Занятость постов отдаёт `GET /api/s/<slug>/load?date=` (только промежутки времени, без данных клиентов). Акцентный цвет задаётся в админке.
- **Выбор стиля в демо:** сверху панель «Боковина / План / Такси» (ссылка `?theme=…`, тему ставит layout через заголовок от `proxy.ts`) и кнопка «Выбрать этот стиль» (`POST /api/s/<slug>/theme`, только для демо). Выбор и дата видны в админке (колонка «Стиль»).
- Есть мобильная и (с последнего коммита) компьютерная версия: на ≥960px шапка на всю ширину с карточкой «адрес / сегодня / телефон», ниже две колонки — контент слева, форма записи справа (sticky).
- Кабинет владельца `/cabinet`, админка `/admin` (воронка, быстрое демо, триал, оплаты), главная avtoslot.ru, `/offer`, `/privacy`.
- 34 теста (vitest), production-сборка проходит.

## Текущая задача: дизайн

Темы сайта выбраны и сделаны (см. выше). Его замечание: **оранжевый акцент выглядит как «сделано нейросетью»**. В темах сайта оранжевого больше нет; остался в бренде Автослота (главная, кабинет, админка, `--color-accent: #ff6a1f` в `app/src/app/globals.css`). Обсуждали варианты бренда: дорожный синий, зелёный «свободно» (цвет свободного окна), жёлтый разметки на графите — не выбран.

Сделано: три направления макетами в `design/directions/` (описание в README там же): «Свободно» (светлый + зелёный), «Боковина» (резина + шина в шапке + выбор радиуса), «План» (запись на плане постов). Ждём выбора Игоря, потом переносим в код как тему(ы).

Где что лежит:
- темы сайта: `app/src/app/s/site.css`, разметка `app/src/app/s/[slug]/page.tsx`, форма записи `booking-widget.tsx`;
- главная: `app/src/app/page.tsx` + `landing.css`;
- цвета тем по умолчанию в админке: `app/src/app/admin/labels.ts` (THEMES);
- старые макеты: `design/mockups.html`.

Правила работы:
- перед правками показывать скриншоты (Playwright, Chromium уже установлен: `/opt/node22/lib/node_modules/playwright`), на ширине телефона 390 и компьютера 1440, без горизонтальной прокрутки;
- коммитить по-русски, пушить в ту же ветку; не говорить «выложено», пока сервер не обновился (автообновление или `update.sh`);
- писать Игорю просто, по-русски, без жаргона.

## Локальный запуск в песочнице

```bash
service postgresql start
cd app && npm install            # если нет node_modules
npx prisma migrate deploy && npm run db:seed
npm run build && npx next start -p 3000
# демо: /s/koleso («Такси», демо с переключателем), /s/kniga («Боковина»), /s/asfalt («План»)
# вход: админ +79990000001 / admin-dev-password, владелец kniga +79990000002 / owner-dev-password
```
