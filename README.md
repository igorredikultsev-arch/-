# Автослот

Сайт с онлайн-записью для шиномонтажей и автосервисов, кабинет владельца и админка для продаж.
Полный план продукта — [PLAN.md](PLAN.md), макеты — [design/mockups.html](design/mockups.html).

## Что уже есть (версия 1 плана)

- **Сайт сервиса** в трёх темах: «Гараж», «Сервисная книжка», «Асфальт». Запись в три шага (услуга, день и время, контакты), только на свободные окна с учётом постов, длительности услуг, часов работы, обеда и праздников.
- **Защита записи**: согласие на обработку данных отдельной галочкой, Яндекс SmartCaptcha, ловушка для ботов, лимиты по IP и номеру, блокировка от двойной записи на одно окно.
- **Страница записи** для клиента: талон, файл для календаря, маршрут, отмена не позже чем за 24 часа.
- **Кабинет владельца**: «Сегодня» с загрузкой постов, «Неделя», запись после звонка, закрытие времени, правка услуг, цен, часов и текстов, смена пароля.
- **Админка**: воронка продаж, быстрое демо за 2-3 минуты, готовый текст первого сообщения, CRM, перевод в пробный период с выдачей пароля, оплаты, статусы.
- **Главная avtoslot.ru**: что это, как подключиться, цены, договор-оферта и политика сервиса (`/offer`, `/privacy`).
- **Обслуживание**: ежедневная очистка (просроченные демо, обезличивание старых записей), резервные копии, сертификаты HTTPS.

Ещё не сделано (версия 2 и дальше в плане): push-уведомления владельцу, Telegram и SMS, загрузка фото, статистика за месяц.

## Как устроено

```
app/                 приложение (Next.js 16, TypeScript, Prisma 6, PostgreSQL)
  prisma/            схема базы и миграции
  src/lib/           логика: расчёт окон (slots.ts), запись (booking.ts), вход (auth.ts), документы (legal.ts)
  src/app/s/[slug]/  сайт автосервиса
  src/app/cabinet/   кабинет владельца
  src/app/admin/     админка
  src/proxy.ts       поддомены и собственные домены клиентов
  tests/             тесты (расчёт окон, гонка записей, очистка)
  deploy/            Caddy и резервные копии
design/              макеты
```

Адреса сайтов:
- **демо**: `https://<ваш-домен>/s/<slug>` — на основном домене, чтобы не тратить лимит сертификатов Let's Encrypt;
- **подключённый клиент**: `https://<slug>.<ваш-домен>` или его собственный домен.

## Запуск на своём компьютере

Нужны Node.js 22 и PostgreSQL 16.

```bash
cd app
cp .env.example .env          # поправьте DATABASE_URL, если нужно
npm install
npx prisma migrate dev        # создаст таблицы
npm run db:seed               # тестовые сервисы и входы
npm run dev
```

Откройте:
- http://localhost:3000/s/koleso — демо в теме «Гараж» (ещё `/s/kniga` и `/s/asfalt`);
- http://localhost:3000/login — админ `+79990000001` / `admin-dev-password`, владелец «kniga» `+79990000002` / `owner-dev-password`.

Тесты (нужна отдельная тестовая база, её адрес в `TEST_DATABASE_URL`):

```bash
npm run test:db   # один раз: миграции в тестовую базу
npm test
npm run typecheck
```

## Запуск на сервере (VPS в России)

**Быстрый путь.** Создайте сервер Ubuntu 24.04, добавьте A-записи домена (`@` и `*`) на его IP, откройте консоль сервера под root и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/igorredikultsev-arch/-/claude/admiring-davinci-ej5p3n/app/deploy/setup.sh | bash
```

Скрипт спросит домен, почту, ФИО, ИНН и телефон, сам сгенерирует пароли и секреты, соберёт и запустит всё, настроит расписание и выдаст пароль админки. Ниже то же самое по шагам.

1. **Сервер.** VPS с Ubuntu 24.04, 2 ГБ памяти, в российском дата-центре (Timeweb Cloud, Selectel, Yandex Cloud). Установите Docker: `curl -fsSL https://get.docker.com | sh`.
2. **Домен.** У регистратора добавьте две A-записи на IP сервера: `ваш-домен.ru` и `*.ваш-домен.ru`.
3. **Код и настройки:**
   ```bash
   git clone <репозиторий> /opt/avtoslot && cd /opt/avtoslot/app
   cp .env.example .env && nano .env
   ```
   Обязательно заполните: `ROOT_DOMAIN`, `APP_URL` (`https://ваш-домен.ru`), `POSTGRES_PASSWORD`, `ACME_EMAIL`, `CRON_SECRET`, ключи SmartCaptcha, `PROCESSOR_NAME`/`PROCESSOR_INN`/`PROCESSOR_EMAIL` (ваши реквизиты, они попадают в согласие и политику). Необязательно: `CONTACT_TELEGRAM` (кнопка «Написать в Telegram» на главной) и `EXAMPLE_SLUG` (какое демо показывать как пример).
4. **Запуск:**
   ```bash
   docker compose up -d db
   docker compose run --rm migrate
   docker compose up -d --build
   docker compose run --rm migrate npx tsx scripts/create-admin.ts +79991234567 "пароль-от-10-символов"
   ```
5. **Расписание** (`crontab -e`):
   ```
   15 3 * * *  cd /opt/avtoslot/app && ./deploy/backup.sh >> deploy/backup.log 2>&1
   30 3 * * *  curl -s -X POST -H "Authorization: Bearer <CRON_SECRET>" https://ваш-домен.ru/api/cron/cleanup
   ```
6. **Обновление:** `git pull && docker compose run --rm migrate && docker compose up -d --build`.

Сертификаты: основной домен получает сертификат сразу. Поддомены клиентов и их собственные домены — при первом заходе, только если клиент подключён (проверку делает `/api/tls-check`).

## Перед первыми продажами

- Покажите юристу шаблоны согласия и политики (`app/src/lib/legal.ts`) и текст оферты.
- Подайте уведомление в Роскомнадзор (раздел 6.3 плана).
- Оформите самозанятость и не забывайте чек в «Мой налог» на каждую оплату: в админке у оплаты есть отметка о чеке.
