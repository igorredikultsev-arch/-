# 3D для стиля «Сканер»

`car.glb` — «Car Concept» из Khronos glTF Sample Assets (https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/CarConcept).

подпись автора стоит в подвале сайта в стиле «Сканер». Убраны номерной знак и логотипы Khronos / 3D Commerce (товарные знаки,
под CC BY не входят), варианты окраски; мелочи салона убраны, дворники, салон и обода упрощены, касательные и вторые развёртки удалены, текстуры WebP до 512 px, геометрия квантована и сжата meshopt. 11,8 МБ → 1,1 МБ (0,8 МБ при сжатии gzip).

`car-m.webp`, `car-d.webp` — кадр сцены «Сканер», пока грузится модель; `wheel-m.webp`, `wheel-d.webp` — первый кадр сборки колеса (0,35 с), пока грузится код сцены. Телефон и компьютер. Снимаются с сайта с `?frame=`.
