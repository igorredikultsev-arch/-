# Новый стиль вместо «Тёмного» (ключ `tire`)

Четыре макета первого экрана с эффектом «как дорогой автосалон», 14 октября 2026. Данные демо «Колесо», запись (радиус, услуга, время) та же, что на сайте. Отдельные HTML-файлы: открываются в браузере без сборки (лучше через любой локальный сервер, например `python3 -m http.server`), телефон 390 и компьютер от 960px в одном файле. В код приложения пока не перенесены.

Вторая версия (по отзыву: «Витрина» и «Сканер» выглядели плоско и дёшево, нужен настоящий 3D; «Драйв» убран).

| Файл | Направление | Главное |
|---|---|---|
| `1-vitrina.html` | «Витрина: сборка колеса» | Настоящее 3D-колесо (three.js, `wheel3d.js`, всё из кода, без моделей): детали стоят по оси и собираются в колесо, потом свет и разворот. Протектор из объёмных блоков, рельефная надпись с названием сервиса и размером шины (меняется с радиусом). Крутится пальцем. |
| `2-skaner.html` | «Сканер: машина на стенде» | 3D-машина (`car3d.js`, модель `app/public/3d/car.glb`): луч от носа к корме, за ним сетка 3D-скана, потом свет, глянцевый пол с отражением, рамки с радиусом и временем на колёсах. Радиус под машиной запускает новый скан. Крутится пальцем. |
| `3-chasticy.html` | «Частицы», как Dala | Без изменений: шина из ~3 тысяч светящихся точек, название выложено точками. |

Общее:
- three.js 0.169 с jsDelivr через importmap (в приложении будет из npm и подгружаться после открытия страницы). Вес: Витрина ~180 КБ кода, Сканер ~210 КБ кода + модель 2,1–2,8 МБ. Пока грузится, на месте сцены картинка (`shots/web/poster-*.webp`, 14–22 КБ).
- Автоподстройка: если кадр дольше ~30 мс, снижается плотность пикселей, в Сканере потом отключается отражение пола. Вне экрана и в фоновой вкладке рисование стоит.
- `?t=2.5` в адресе останавливает время (снимки по кадрам). При `prefers-reduced-motion` — конечный кадр.
- `common.js` и `base.css` — блоки ниже первого экрана (радиус, запись, услуги, отзывы, контакты, подвал). Значки — пути Phosphor regular.
- На витрине claude.ai файлы .glb не отдаются, модель там опубликована как `models/car-glb.wasm` (то же содержимое), страница пробует оба адреса.

Витрина со сравнением и живыми макетами: `index.html` (выложена как артефакт https://claude.ai/artifact/Pd6AEbrNHPBW4FnV4jsw1L). Снимки: `shots/web/` (WebP: первый экран 390 и 1440, вся страница 390, кадры анимации, картинки-заглушки). Снимки делались Playwright с `--enable-unsafe-swiftshader --use-angle=swiftshader` (WebGL без видеокарты).
