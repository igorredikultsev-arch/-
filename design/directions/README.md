# Направления дизайна сайта автосервиса

Три макета страницы `/s/<slug>` на данных демо «Колесо». Это отдельные HTML-файлы: открываются в браузере без сборки, ширина телефона и компьютера (от 960px) в одном файле. В код приложения пока не перенесены.

| Файл | Направление | Главное |
|---|---|---|
| `1-svobodno.html` | «Свободно», сильная спокойная база | Светлый фон, зелёный = свободное время. Ближайшие окна прямо в шапке, кнопка «Записаться на 13:20». Шрифт Geologica. |
| `2-bokovina.html` | «Боковина», смелый | Цвет резины, шина с надписью по кругу в шапке. Сначала радиус R13–R22, по нему сразу цена. Шрифты Unbounded + Golos Text. |
| `3-plan.html` | «План», необычный | Вид сверху на посты сегодня: занятые места с машинами, свободные размечены жёлтым. Нажал на место — выбрал время. Шрифт Sofia Sans (обычная и сверхузкая). |

Общее для всех трёх:
- оранжевого нет; акцент у каждого направления свой и со смыслом (свободно / метка на шине / разметка);
- список услуг больше не повторяется дважды (раньше он был и в «Услугах», и в первом шаге записи);
- на компьютере запись справа и остаётся на виду при прокрутке.

Снимки: `shots/`. Как снимать заново — Playwright, ширина 390 и 1440 (см. CONTEXT.md).
